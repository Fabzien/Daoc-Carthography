# Daoc-Carthography

Daoc-Carthography is a "Google maps" like maps of Dark Age Of Camelot MMORPG (https://www.darkageofcamelot.com/).

## Development
Requires Node.js 22.12+.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build into dist/
npm test           # Vitest
npm run lint
```

Mob search needs the URL of the mob API in a `.env.local` file:

```
VITE_API_ENDPOINT=https://example.com/mobs
```

Stack: Vite, React 19, TypeScript, react-leaflet, Zustand, MUI.
